# Flask Shop API

Простой REST API интернет-магазина на Flask с использованием PostgreSQL и фонового планировщика для периодической загрузки и обновления данных из внешнего API.
---
## Описание

Данное приложение реализует API для работы с товарами и категориями магазина.  
- Используется Flask + Flask-SQLAlchemy для веб-сервера и работы с базой данных.  
- PostgreSQL — в качестве СУБД.  
- Планировщик, работающий в отдельном потоке, регулярно загружает и обновляет данные из внешнего API.  
- Логи пишутся в консоль и в файл `logs/app.log`.

## Установка и запуск

### 1. Клонировать репозиторий

git clone <URL_репозитория>
cd <папка_проекта>

### 2. Настроить переменные окружения

.env

### 3. Запустить Docker

docker-compose up --build -d
